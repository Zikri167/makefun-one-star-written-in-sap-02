[One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
competition on [make.fun](https://make.fun).

## The entry

> One star. She has moved me six times this month chasing "good light" and finally parked me on top of the fridge next to the Wi-Fi router, where I photosynthesize pure regret for a living.

## How it works

`main.ts` (Node 22, stdlib only) writes exactly that one line to `/output/entry.txt`.
Deterministic — no network, no randomness, no time dependence. Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
